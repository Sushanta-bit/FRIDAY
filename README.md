# FRIDAY-ai-assistant

AI-powered personal voice assistant built using React.js and Groq API that responds to user queries, processes voice commands, and performs tasks such as opening YouTube, Google, LinkedIn, and WhatsApp.

## Features

- AI-powered conversational assistant
- Voice command recognition
- AI-generated responses using Groq API
- Open YouTube, Google, LinkedIn, and WhatsApp through voice commands
- Interactive and responsive user interface
- Real-time user interaction
- State management using React Context API

## Tech Stack

### Frontend

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

### AI Integration

- Groq API
- Groq SDK

### Other Technologies

- Web Speech API
- React Context API
- Git & GitHub
